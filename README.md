# Gheorghe 24/7 Recovery — demo homepage

Static demo site (plain HTML, CSS and vanilla JS, no build step).

```
index.html
assets/css/style.css
assets/js/main.js
assets/img/favicon.svg
```

## Run locally
Open `index.html` in a browser, or serve the folder: `npx serve .`

## Deploy on Vercel
Import the repo in Vercel with the framework preset set to **Other**. There's no build command, and the output directory is the root.

## Before going live
- Swap the Unsplash photos for the client's real photos. Search `PLACEHOLDER` in `index.html`.
- Add real Google reviews and the client's Google review link (also marked `PLACEHOLDER`).
- Check the list of areas.
- Once there's a domain, set an absolute `og:image` and add `url` to the JSON-LD.
